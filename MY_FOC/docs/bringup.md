# 硬件接入、启动模式与故障诊断

## 1. 当前硬件映射

本表来自当前源码和Keil器件配置，不替代实际电调原理图。

| 信号 | 当前映射 |
|---|---|
| MCU | STM32F405RGTx，Cortex-M4F，系统时钟168 MHz |
| 三相高侧PWM | PA8 / PA9 / PA10：TIM1_CH1 / CH2 / CH3 |
| 三相互补PWM | PB13 / PB14 / PB15：TIM1_CH1N / CH2N / CH3N |
| 三相电流ADC | PC0 / PC1 / PC2：ADC1_IN10 / IN11 / IN12，注入Rank 1 / 2 / 3 |
| 编码器SPI | SPI1：PA5 SCK、PA6 MISO、PA7 MOSI；PA4片选 |
| 驱动器SPI | SPI3：PC10 SCK、PC11 MISO、PC12 MOSI；PC9片选 |
| 驱动使能 | PB5 |
| nFAULT | PB7，低有效，下降沿中断 |
| USB | USB FS CDC，JustFloat遥测 |

相序、采样极性、CSA增益和编码器方向都依赖实际布板。当前换算系数是0.0403 A/LSB，启动时通过1000次成功ADC转换计算三相零偏。该系数不是所有DRV8323电调通用值。

DRV8323初始化向0x06写入0x2C0并回读比较。寄存器位含义、VREF接法与CSA增益应对照实际芯片资料和板级电路确认，不应只根据历史注释判断。

## 2. 启动模式

### 默认：位置闭环试运行

```c
FOC_ENABLE_POWER_ON_MOTION = 1
FOC_SPEED_TRIAL_ENABLE = 1
foc_mutipos_turn = 8.0f
```

此路径直接使用候选机械offset `4.72575378°`、方向+1及7极对进入运行，不执行本次正反扫描，也不自动写Flash。`foc_aligned=1`在此路径代表允许使用当前角度配置，不代表offset已通过独立精度验收。

`FOC_SPEED_TRIAL_TARGET_RAD_S`在位置模式下作为输出速度的幅值上限。目前50 rad/s约为7.96圈/秒；若需要肉眼计圈，可以单独降到6.283185 rad/s，约1圈/秒。完成8圈时编码器累计反馈应为2880°。反馈显示2880°与独立机械计圈是两种验证，不能互相替代。

### 对齐诊断路径

`FOC_SPEED_TRIAL_ENABLE=0`才进入对齐路径；当前还设置了强制重新标定和只诊断模式。流程包含电流渐增、方向/极对数检查、正反扫描、圆周平均offset及七点核验。

只诊断模式禁止把候选结果直接保存；只有通过验证并满足保存门控，且关闭只诊断模式，才进入Flash事务。当前宏组合不等于“首次上电标定保存、以后永久复用”的产品化行为。

## 3. Flash布局

最后128 KiB的sector 11，地址0x080E0000～0x080FFFFF，作为标定记录区；应用链接区应限制在之前的0xE0000字节内。

记录包含配置标识、极对数、方向、offset、圆周一致性量、已验证标记、CRC32及最后写入的提交标记。保存后回读比较并刷新Flash缓存；加载时检查配置、数值和CRC。不要将应用固件或其它数据覆盖到该记录区。

## 4. 两种故障值不要混淆

`motor_safety_fault`是板级安全停机编号，`motorVars_M1.faultMtrNow`是电机/对齐模块枚举。数字相同不代表含义相同。

| `motor_safety_fault` | 源码中的主要含义 |
|---:|---|
| 0 | 尚未锁存板级故障 |
| 2 | nFAULT或相关启动检查失败 |
| 4 | 相电流越限或ADC接近量程边界 |
| 5 | ADC或主循环心跳超时 |
| 6 | 停止请求/诊断流程主动停止 |
| 7 | 原有运行时限到达，目前280秒 |
| 8 | 连续编码器读数错误 |
| 10 | 已存在停机标志的重复关断路径；首个故障通常另有编号 |
| 11 | PWM通道启动失败 |
| 12 | 电机/对齐模块要求停机，继续查看`faultMtrNow` |

电机枚举另包含参数、编码器、电流、超时、方向、Flash、过流和offset检查失败。具体值以`motor1_drive.h`和停机调用点为准。

## 5. 分层限幅

| 层级 | 当前值 | 用途 |
|---|---:|---|
| 位置环速度输出 | ±50 rad/s | 限制速度参考 |
| 速度PI输出 | ±3 A | 限制Iq参考 |
| 运行电压矢量 | 2 V | 限制sqrt(ud²+uq²) |
| 对齐相电流快速保护 | 4 A | 对齐期间ADC回调保护 |
| 运行相电流快速保护 | 15 A | 运行期间ADC回调保护 |
| 前台连续过流检查 | 10 A，连续8次检查 | 原有前台保护 |
| 驱动芯片硬件故障 | 由DRV8323配置及硬件决定 | 与软件Iq限幅独立 |

Iq参考为3 A，不意味着相电流保护阈值也是3 A。运行电压限幅目前在宏定义和启动合法性检查中都约束为不超过2 V，修改时要对应检查。

## 6. 重要时序约束

- ADC注入采样由TIM1_CC4触发，电流环位于ADC回调；不要把USB发送或阻塞SPI搬入此中断。
- 当前三相通道在同一ADC内依次转换，并非三个ADC同时采样。
- 采样时间配置为15 ADC cycles，CCR4为4099。该配置不是“任意占空比下一定在有效零矢量窗口”的证明，移植时应核对PWM模式、极性、死区及采样建立时间。
- 编码器通信采用两帧流水读取，并检查奇偶校验、EF和角度跳变；软件跳变门限不能替代电气信号质量验证。
- DWT计数器用于SPI微秒等待、观测器dt和控制时序统计。若调试工具关闭DEMCR.TRCENA或DWT.CYCCNT，依赖计数器的等待可能不再返回。读取一次RAM中的旧角度不等于编码器仍在持续更新；应同时核对`enc_valid_count`和时间戳。
- 多圈位置依赖连续的有效角度轨迹。相邻计圈样本间若越过半圈且中间样本丢失，最短角差无法恢复遗漏运动。

## 7. 当前测试边界

主机测试可以验证公式、跨零、方向、限幅和状态门控；不能证明电流采样窗口、真实转矩、绝对位置精度、功率器件可靠性或全部转速下的闭环稳定性。

0.5°机械位置误差是调试目标，当前没有独立测量记录可作为保证。低速减速末段仍可能有轻微卡滞，多圈反馈与机械标记的独立对照仍应完成。
